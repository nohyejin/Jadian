#feature

**분류**: 전화 상담
**세일즈 가치**: 콜 유실률 감소 / 전화 → 채팅 전환

## 설명
IVR로 문의 유형에 따라 적절한 상담원·팀 연결. 전화번호 발급 / 착신전환 / 운영시간 분리 / 워크플로우 시나리오 / 콜백·음성사서함 / 라우팅 설정.

**핵심 논리**: 채팅 전환 시 해결률이 높고, 전화는 유실률이 높음. 채팅은 데이터 축적에도 유리.

⚠️ 010 번호는 수신 가능·**발신 불가**. 070은 스캠으로 인식되어 전환율 낮음. 법인폰 필요.
