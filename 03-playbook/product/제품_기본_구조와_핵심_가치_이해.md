# 고객 경험 (front)

==이 기능은 어떤 문제를 해결하기 위해 만들어졌을까?==
접객의 태도가 전환율에 큰 역할. 온라인 비즈니스에도 고객을 접객할 수 있는 전문가 같은 역할이 필요하다.

**올인원 AI**
* 상대를 잘 알고, 상대가 원하는 말을 캐치해서 말을 걸어야겠다. 상담 기능 + CRM
* 채널톡 마케팅 강점 - CRM으로 고객의 유의미한 데이터를 가짐, 고객을 아는 상태로 대화하는 마케팅 
* 상담 태그 기능 - 상담 분류, 지금 집중해야 할 상담이 무엇인지 구분 

CS(Customer Service) - 고객센터에 문의했을 때 질문에 응대
CX(Customer Experience) - 고객 경험 설계 

==가장 먼저 해결하고자 했던 문제: 언제 어디서든 고객 문의에 답할 수 있는 환경==
* 채널톡을 접하는 고객은 상담이 편해진다 / 경쟁사는 회원만 상담 가능 
* 팔로우 알림
	* 특정 상담을 시작했을 때 고객에게 개인정보를 받음 $\rightarrow$ 답변 알림 (대화 단절 경험 X)
	* 답변 내용을 요약해서 SMS로 전송하고 링크로 follow-up

**CRM**
* 상담시 고객 행동 서비스 수집 $\rightarrow$ 차별화된 경험 강화

# 상담원 경험 (desk)

## **팀챗**
* [As-is] 상담원만 사용하는 커뮤니케이션 툴 $\rightarrow$ [To-be] 팀 전원에게 고객 문의를 공유
* 내부 커뮤니케이션과 고객과의 외부 커뮤니케이션의 단절을 피할 수 있고, VOC의 가시성 높아짐

## **수신함**
* 목적: 상담을 팀 단위로 관리하기 위함, 상담 태그를 활용하는 통계

* **좌측 패널**: 진행 중인 상담 수 / 내가 해결 중인 / ALF가 해결 중인 / 팀별 / 상담 태그와 수
	* 관리가 쉽고, 품질 모니터링 실시간으로 가능
	* 연동 서비스: 전화, 이메일, 카카오, 네이버 톡톡, 인스타그램을 하나의 채널에서 관리
	* [As-is] 여러 개의 채널에서 상담을 관리 $\rightarrow$ [To-be] 옴니채널 관리로 누락 가능성 감소
	* 고객이 어떤 워크플로 / 버튼을 통해서 들어왔는지 확인 $\rightarrow$ `나에게 배정` (현황 확인)

* **중앙 패널(1): 내부대화**
	* 기획 의도: 전 직원들이 고객과 직접 소통해서 문제를 해결하는 고객 중심의 문화
	* 고객에게 즉시 답변 or 내부대화를 통해 관련된 멤버를 상담에 관여 가능 
	* 주니어 상담사의 온보딩이나 내부 대화를 통한 교육 지원

* **중앙 패널(2): 매크로**
	* 자주 사용하는 템플릿을 만들어 두고 `#`으로 지정된 문구를 보내는 기능
	* 가치: 높은 퀄리티의 상담과 일관된 고객 퀄리티

* **우측 패널**
	* 고객 정보나 상담 정보를 한눈에 모아볼 수 있는 패널
	* 고객 정보를 확인해서 이전 상담 내역, CRM, 주문 내역, 개인화 마케팅 (트래픽 기반)

## ==AI ALF==
* 채널톡이 지속적으로 고민해 온 CS 시장은 AI가 충분히 대체할 수 있는 시장
* 고객은 즉각적으로 답을 받기를 원하는 상담 트렌드의 변화

**규칙**
* ALF가 상담을 할 때 따라야 할 매뉴얼을 주는 것
* 톤앤매너 / 역할 / etc
* AI에게 고객 맞춤형 프롬프트를 학습시킬 수 있다

**지식**
* ALF가 답변하는 지식을 모아두는 지식 창고
* hallucination을 최대한 줄이기 위해 지식 설정
* 다양한 포맷의 자료를 업로드 가능 (웹사이트, 액셀, pdf, etc)
* **도큐먼트**: 채널톡 내에서 사용 가이드, 블로그, 릴리즈 노트 등 공개

**태스크**
* 답변 & 단순 업무 상담 처리까지 가능한 기능
* AI 고도화를 통해 복잡한 고객 요청도 ALF 태스크로 자동으로 해결
* 상담 해결률 80%
* 빠른 배포: 바로 AI가 답변하도록 설정 

## 워크플로우
* 상담 전 상담원 리소스 효율화
* 상담 중 단순 반복 문의 자동화
* 상담 후 만족도 향상
* 노코드 기반으로 비개발자도 버튼형 제품 생성 가능
* FS팀에 온보딩에 대한 책임 존재

## 고객연락처
* 상담을 했는데 고객을 기억하지 못하는 문제 해결
* [As-is] 데이터베이스 엑셀 사용은 비효율적 $\rightarrow$ [To-be] 채널톡 연동을 통해 효율적으로 사용 
* ==필터링==: 집중해야 할 고객을 선별해서 집중

## 분석
* 상담 통계를 데이터로 분석하기 위해 존재하는 기능
* CX가 CX로 넘어가기 위해 가장 도움이 되는 기능 
* 상담 퀄리티, 요일대, 시간대 등의 통계, 오퍼레이터 퍼포먼스, 상담 목표 추적
* 상담 목표 설정 - 실제 커뮤니케이션의 결과가 어떤 임팩트를 냈는지 자신 있게 파악
* **CX에서도 매출을 내고 비즈니스와 팀에 개선할 수 있다는 것을 수치로 증명** 
* ==상담 태그==를 적절히 활용

## 도큐먼트
* 기업의 아티클을 한번에 관리

## 마케팅
* 먼저 말을 거는 기능
* 유의미한 고객 정보, CRM 데이터, 상담 데이터를 활용한 타겟팅 메시지

## 미트
* 전화 상담이 꼭 필요한 비즈니스에서 사용 (연령대가 높거나, 전화를 선호)
* 전화 상담과 채팅 상담을 하나의 채널에서 관리 
* 물리적 제약 없이 채널톡 서비스 내에서 전화를 걸 수 있음
* 전화 상담 이후 상담 내용을 자동으로 녹음()
