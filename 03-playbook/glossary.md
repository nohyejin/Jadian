#glossary

# 용어집

| 용어 | 뜻 |
|---|---|
| **AHT** | Average Handling Time — 상담원이 문의 하나를 처리 완료할 때까지 걸리는 평균 시간 |
| **AICC** | AI Contact Center — 보이스봇까지 아우르는 고도화된 컨택센터 |
| **BPO** | Business Process Outsourcing — 업무 대행. CS 위탁 운영 |
| **CSAT** | 고객 응대 만족도 |
| **CTI** | Computer Telephony Integration — 통신사 제공 전화 시스템. STT 퀄리티 낮고 회선당 비용 구조 |
| **IVR** | Interactive Voice Response — 문의 유형에 따라 상담원·팀을 연결하는 음성 응답 |
| **LTH** | 세일즈 forecast 배수 지표 |
| **PMS** | 호텔 예약 연동 시스템 |
| **PQL** | Product Qualified Lead — 인바운드. 채널톡을 인지하고 있는 기업 |
| **RAG** | Retrieval-Augmented Generation — 학습이 아닌 참조 방식. 채널톡 AI가 사용 |
| **ROAS** | Return On Ad Spend — 광고 수익률 |
| **SQL** | Sales Qualified Lead — 아웃바운드. 타겟 기업을 직접 선정 |
| **TCK** | CS·컨택센터 업무 위탁 운영 BPO 전문 기업 |
| **TCO** | Total Cost of Ownership — 총소유비용. 초기 비용, 유지비, 전체 수명 주기 총비용 정량화 |
| **WMS** | Warehouse Management System — 창고 관리 시스템 ([[사방넷]], [[SAP]] 등) |
| **셀프젠** | AE가 스스로 영업 기회를 발굴하는 것 |
| **턴키** | 의사결정자가 열쇠만 돌리면 바로 입찰 가능한 일괄 계약 |
| **취교반배** | 취소·교환·반품·배송 — 커머스 단순 반복 문의 4종 |
