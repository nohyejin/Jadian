## 판정이 애매할 때

```
⚠️  확인 필요
  한빛리테일 — 리드마켓 블록이라 기본값은 '학습 딜'입니다.
              Jade님이 직접 콜한 딜이면 01-accounts로 옮길까요?
```

콜 로그 표에 있었거나 `[내딜]` 마커가 있으면 묻지 않고 바로 `01-accounts/`로 간다.
