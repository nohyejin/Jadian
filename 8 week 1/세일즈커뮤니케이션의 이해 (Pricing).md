# 좋은 세일즈란

* Pain Killer - 고객이 갖고 있는 문제가 무엇일지, 고통스러울지 진단 후 채널톡으로 해결하는 세일즈
* 기초 세일즈 내러티브 - 상담원을 줄이는 도구가 아니라 업그레이드하는 인프라
	* CS 자동화 > 리소스 절감 > 전략적 리디렉션 > 매출 성장

1. **비용 줄이기 - CS 시장의 인건비 기반으로 접근**
	* 일반적으로 CS를 비용으로 인식: 비용 중 가장 큰 파이가 인건비
	* 1인이 지속가능하게 처리하는 상담량은 30-50건
	* 월 급여 300-400, 만족도 낮고 이직률 높음 $\rightarrow$ ==병목과 비용 발생==
	* 문제는 환경: 인력을 전략 없이 반복 업무에 쓰는 구조

ALF 도입 $\rightarrow$ ==동일한 인력으로 운영 비용 합리화==
* 단순 반복 문의의 *80%* 는 AI가 처리
* 상담사는 고부가가치

2. **매출 높이기**
	* AI 시대에 *데이터* 중요도 높음
	* 이탈 신호 포착 / 불만 패턴 식별 / 매출 인사이트 / 선제적 VIP 케어
		* 베리시가 VoC 기반으로 신제품 출시하여 매출 상승 / 브랜드 팬덤(단골) 형성
	* 채널톡 VIP 고객 - Enterprise 고객 (VIP 대상 채팅, 교육)
		* 파레토의 법칙: 상위 20% 가 매출의 80% 를 견인
	* ALF로 인해 감소한 리소스를 다양하게 분배하여 활용

# 비전 / 기능 / 가격 세일즈

## Visionary Sales - 미래와 가치를 파냄
* 팀과 비전을 판매, 고객의 성공을 정의, 채널톡의 성공과 연결

* Team history - 채널코퍼레이션의 미션과 철학
* 채널톡이 생각하는 AI CX 프레임워크
* 고객의 성공을 정의하고, 채널톡의 성공과 연결하는 프로포절
* 적절한 비저너리 세일즈의 예시 학습

* ALF - 채널톡 알프를 통해서 상담 효율화, 업무 과중을 해소, 궁극적으로 매출 창출 가능 (미래의 가치를 전달)
* Win-win 파트너: 성장하고 비즈니스가 성장할수록 채널톡도 함께 성장할 것이다

# Feature Sales - 고객이 겪는 문제
* 고객이 가진 문제를 **정확하게 진단**하고 채널톡의 **기능**과 연결

1. **채널 통합**: 문의 분산, 고객 히스토리 파편화, CS/세일즈/마케팅 협업 단절 $\rightarrow$ 액션 활용
		$\Rightarrow$ **수신함**에서 확인. 창 여러개 x, 누락 x, 상담 몇 개인지 바로 보고 컨트롤
	* 채널 통합 / 누락 방지 / 태그, 분류, 고객 속성 구조화 $\Rightarrow$ 통계, 분석 / AI 선제 분석

2. **상담 효율화**: 문의량 과중, 성수기/행사 대응 비용, 단순 반복 문의 대부분, 번아웃/이직
		$\Rightarrow$ **ALF** 도입으로 반복/단순 문의 처리
	* AI가 반복/단순 문의 처리, 업무 부하 해소, 고부가가치 업무(불만 케어, 업셀, 복잡한 CS), 성수기나 행사에도 인력 추가 없이 볼륨 흡수, 운영 비용 유지

3. **컨버전/리텐션**: 응답 지연으로 구매 이탈, 업셀/크로스셀 기회 놓침, 이탈 징후 사전 파악 X
		$\Rightarrow$ 상담 데이터 기반 이탈 유인 파악, 고객 세분화 후 타겟 마케팅, 이탈 징후 사전 감지

* Feature만 강조하면 경쟁사와의 차별화 불가 - visionary sales와 섞어서 사용
* 없는 기능 - 해당 기능에서 원하는 가치가 무엇인지, 어떤 것을 얻고 싶은지 $\Rightarrow$ 채널톡 기능으로

# 설득의 논리 전개

1. 이런 문제가 있으시군요 (공감)
2. 이런 솔루션을 제안드립니다
3. 근거: 데모 / 레퍼런스 / 성공사례
4. 가격은 매우 합리적입니다
5. 경쟁사 대비 이런 점이 좋습니다
	* (CS) 해피톡 / (마케팅) 데이터라이즈
6. 다음 일정은 이렇게 안내드립니다
> 문제 공감에서 시작해 다음 액션(일정)으로 반드시 마무리
